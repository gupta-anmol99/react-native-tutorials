## Expo vs React Native CLI
There are two approaches for creating a RN app. The first is called expo and other is the native CLI. Expo is the recommeded approach for creating RN apps.

* Expo CLI: A third party service that provides a set of tools to build. Creating apps and using native features like camera, push notifications, etc. is easier with expo. It is a good choice for beginners.

* React Native CLI: It is the official way to create RN apps. It is more complex than expo but it provides more flexibility and control over the app.

## Creating a new project
Please make sure that you have node js installed on your system. To create a new project, run the following command:

``` npx create-expo-app@latest my-new-project ```

Now if you use the above command as it is, it will create a default template for the project with Expo CLI, Expo router library adn Typescript configuration.

If you want to create a project with bareminimum configuration, you can use the following command:

``` npx create-expo-app@latest --template blank my-new-project  ```

Read more about the teamplates [here](https://docs.expo.dev/get-started/create-a-project/)


## How to use Expo Go app for real time testing
Expo Go is an app that you can install on your phone to test the app in real time. You can scan the QR code generated by the expo CLI to run the app on your phone.

To use Expo Go, follow the steps below:
1. Run ```npm start``` to start the expo server. It will give you a QR code that can be scanned. For android, the code can be scanned in the app but for iOS, you will have to scan the qr code from camera.
2. Grant any permission that expo go app requires and you will see the app running on your phone.


## Basic Components and Styling

### Components

In react native we cannot use the HTML tags like div, h1, h2, etc. Instead we have to use the components provided by react native. Some of the basic components are: View, Text, Image, Button, TextInput, ScrollView, FlatList, SectionList, etc.

You can learn more about the components [here](https://reactnative.dev/docs/components-and-apis)

Some important Basic Components:
- **View**: It is like a div in HTML. It is used to wrap other components. 
- **Text**: If we want to display text, we use the Text component. Remember we cannot display text directly like in HTML.
- **Button**: A self closing tag that is used to create a button. It has a title prop which is the text displayed on the button.

### Styling

We don't have CSS in react native. Instead we have StyleSheet which is an object that contains the styles for the components.

To style we will use the style prop of the component. This prop is not available for all components but most of the components have this prop. We can do styling inline or we can create a StyleSheet object and use it, latter is recommended.

```
const styles = StyleSheet.create({
  appContainer:{
    padding: 50
  },

  inputContainer:{
    flexDirection: 'row',
    justifyContent: 'space-between',
    marginTop: 20,
    marginBottom: 20,
  },

  textInput:{
    borderColor: 'black',
    borderWidth: 1,
    padding: 10,
    width: '80%',
    marginRight:8
  }
});
```

We can use the above styles in the component like this:

```
<View style={styles.appContainer}>
    <View style={styles.inputContainer}>
        <TextInput style={styles.textInput} placeholder='Enter New Goal!' />
        <Button title='Add Goal'/>
    </View>
    <View>
    <Text>List of goals....</Text>
    </View>
</View>
```

### Difference in Styling between iOS and Android
There are some differences in styling between iOS and Android. For example, if you use borderRadius in a Text component, you will get rounded corners in Andorid but not in iOS.
So what can we do? We will wrap the Text component in a View component and apply the borderRadius to the View component.

### Making Scrollable Content
By default, the content is not scrollable in react native. For making screen scrollable, we can use **ScrollView** component. This component is used to make the content scrollable. Now be cautious that ScrollView does make the area scrollable but the the amount of area is determined by the parent contaienr of ScrollView. So always wrap the ScrollView around with a View component and use flex property to make the ScrollView take the entire space.

Now there is another problem. ScrollView renders all the items at once. So if you have a large list, it will render all the items at once which is not good for performance. So we use **FlatList** component. FlatList is used to render a list of items. It is more efficient than ScrollView. It only renders the items that are visible on the screen. It also provides a better performance for long lists. The way we use FlatList is a bit different than that of ScrollView. 

```
<FlatList
    data = {courseGoals}
    keyExtractor = {(item, index) => item.id}
    renderItem = {itemData => (
        <View style={styles.listItem}>
            <Text>{itemData.item.text}</Text>
        </View>
    )}
/>
```

In the above code, the courseGoals is an object: {text: "Random Text", key: randomKey}. FlatList also requires a key prop. If the key in the obejct is stored as key name, then the FlatList will automatically take it. If the key is stored as id, then we have to specify the keyExtractor prop in the FlatList.

### Touchable Components
If we want to make a component pressable, then we can use the `<Pressable>` tag. This makes the component pressable. Inside this, there is a prop called `onPress` which is a function that is called when the component is pressed.

### How get ripple effect in android and ios
In android, the ripple effect is simple and can be done simply by using `android_ripple` prop in the Pressable component.

```
<Pressable android_ripple={{color: '#dddddd'}}>
```

In iOS, the ripple effect is more complex and can be done by using `Pressable` component with `style` prop.

```
<Pressable style={({pressed}) => pressed && styles.pressedItem}>
```


## Layouts and Flexbox
Layouts are typically created using flexbox. Flexbox is a layout model that allows us to position elements in a container. 

Flexbox is all about two axes you have in a container. The main axis and the cross axis. The main axis is the primary axis along which the elements are laid out. The cross axis is perpendicular to the main axis.

The main axis is defined by the flexDirection property. flexDirection can be row, row-reverse, column (default), column-reverse. The `justifyContent` property is used to align the items along the main axis. The `alignItems` property is used to align the items along the cross axis.

Check `/02layouts` for simple codes.

### Deepdive into FlexBox
Tags like View are inbuilt flex containers. They have a default flexDirection of column. 

Let's say for the parent View container, you did this-
```
<View style={{flexDirection: 'row'}}>
    <chil1> <subchild1> </subchild1> </child1> 
    <child2> <subchild2> </subchild2> </child2>
</View>
```

Now the children don't have any height/width specified, then the child will take the height and width that is required by the by the child elements.

Now, if we specify the height/width in parent container, like this:

```
<View style={{flexDirection: 'row', width: '80%', height: 300}}>
    <chil1> <subchild1> </subchild1> </child1> 
    <child2> <subchild2> </subchild2> </child2>
</View>
```

We see the result that the children take the height of the parent container but the width has no impact here. This is the default behaviour of the flexbox. When defulat, the children will stretch in the cross axis but will take the required space in the main axis. So in the parent container, by default, you have alignItems: stretch and justifyContent: flex-start. You cannot use stretch in the main axis in parent container.

To make the changes around the main axs in the children, **you will have to use flex property in the child.** Flex property is the property that is applied to the items inside the flexbox. This property tells how much space an item should take in the container. It basically defines a ratio of the space that the item should take.

## What is bind and arrow functions in React Native
In react native, if we want to pass a function to a component, we have to bind the function to the component. This is because the function is not bound to the component by default.

For example, let's say we have two components: GoalInput and GoalItem. GoalInput uses GoalItem to render the individual goals.

In modern react, we can use arrow functions to bind the function to the component. So we dont need to bind the function to the component.

This is wrong-

```
<Pressable onPress={props.onDeleteItem(props.id)} >
```

Because this will call the function immediately and pass the result to the onPress prop. Instead we should use arrow function to bind the function to the component.

This is correct-

```
<Pressable onPress={() => props.onDeleteItem(props.id)} >
```
